# Lab 1: Requirements Engineering and UML

## Problem Statement #10: Campus & Academic Operations

**Project:** Student Club Event Ticketing & Budget Portal

### Objective
To identify, analyze, and document the functional and non-functional requirements of the proposed system and represent its interactions using UML.

### Deliverables
- Requirements table
- UML Use-Case Diagram
- Use-case flow specifications

### Outcome
The system requirements and user interactions are documented to establish a foundation for software design and development.
