# Lab 3: Architecture Selection and Justification

## Problem Statement #10: Campus & Academic Operations

**Project:** Student Club Event Ticketing & Budget Portal

### Objective
To select and justify a suitable software architecture for the proposed system.

### Selected Architecture
**Microservices Architecture**

### Deliverables
- Architecture selection and justification
- Microservices architecture design
- Component diagram

### Outcome
The system architecture is defined by organizing functionality into separate services, providing a structural foundation for implementation and future maintenance.
